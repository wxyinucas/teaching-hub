# W01 教师运行表（v0.1）

> 三节连上，每节 50 分钟；课间 10 分钟。约 25 名零基础学生，无助教。  
> 现场只盯一件事：第 40 分钟停止开启新问题，最后 10 分钟形成有效证据。

## 课前最低准备

- 在一台可重启的 Windows 设备上亲自跑通[学生任务卡](./W01-学生任务卡.md)；
- 本地保存 Slides/PDF 与 Microsoft、VS Code 官方链接；
- 选择一个能记录提交时间的状态收集入口；
- 明确没有管理员权限、非 Windows、持续网络失败学生的临时参与方式；
- 不准备逐台维修，个别故障只帮助学生形成可接续记录。

## 课时 1｜AI 都能写，为什么还要你签字？

**课堂出口**：完成责任退出卡，能够区分漂亮结果、符合规格和未来盈利。

| 时间 | 核心块 | 教师动作 | 学生动作 |
| --- | --- | --- | --- |
| 0～6 分 | 冷开场 | 投影 Slides 1，发起投票，不急着给答案 | 写下“Agent 完成后我还负责什么” |
| 6～24 分 | 38% 与陌生测试 | 用 Slides 2～3 讲一个偷看未来的假设案例；只讲测试为什么能击穿 | 决定是否愿意签字，并在揭晓后修正理由 |
| 24～40 分 | 责任主线 | 用 Slides 4～5 收束为“目标/禁止项—Agent—证据—决定”；Slides 6 只快速展示课程去向 | 回答盈利、亏损分别不能证明什么 |
| 40～50 分 | 收口 | 投影责任退出卡和 W1 阶梯；停止扩展讨论 | 提交退出卡并确认设备状态 |

**弹性块**：Slides 6 的 16 周地图口头展开。

**超时删减顺序**：先只展示不讲解 16 周地图；再取消“两种未来”的第二轮追问；不删除泄漏案例、责任结论和退出卡。

**只需说清的三句话**：

1. Agent 可以完成实现，但不能替你规定什么算完成；
2. 测试通过只能支持有限主张，不保证未来盈利；
3. 课程评价你能否提出规格、判断证据并为 `ACCEPT/HOLD/BLOCKED` 负责。

## 课时 2｜让 WSL 成为可用状态

**课堂出口**：提交 `READY-WSL`，或一份结构化 `BLOCKED-*`。

| 时间 | 核心块 | 教师动作 | 学生动作 |
| --- | --- | --- | --- |
| 0～8 分 | 入口与安全 | 明确命令运行环境、管理员权限只用于 `wsl --install`、停止条件和状态码 | 打开任务卡，确认设备能否重启和使用管理员权限 |
| 8～18 分 | 唯一黄金路线 | 完整演示一次“管理员 PowerShell → `wsl --install` → 重启 → 初始化 Ubuntu → 验证” | 只观察并在任务卡标记自己的入口状态 |
| 18～30 分 | 滚动安装 | 处理全班共同问题，不逐台接管 | 沿任务卡推进；允许 Agent 解释错误 |
| 30～40 分 | 状态检查后继续 | 统计故障类型；同错达到 5 人则统一说明 | 更新检查点，继续当前步骤，不开启旁支路线 |
| 40～50 分 | 收口 | 宣布停止开新问题，按状态集中处理 | 提交 `READY-WSL` 或结构化 `BLOCKED-*` |

**弹性块**：第二遍完整演示。

**超时删减顺序**：先删 WSL 原理；再删第二遍演示；个别深度维修直接转 `BLOCKED-*`。安全边界、黄金路线和状态提交不可删除。

## 课时 3｜从 WSL 打开 VS Code

**课堂出口**：提交 `READY-CODE`，或一份结构化 `BLOCKED-*`。

| 时间 | 核心块 | 教师动作 | 学生动作 |
| --- | --- | --- | --- |
| 0～8 分 | 恢复与分流 | 按 `READY-WSL / BLOCKED-*` 分组；只统一处理多人共同故障 | 从上节保存的检查点继续 |
| 8～18 分 | 接入演示 | 演示 Windows 版 VS Code、Microsoft WSL 扩展、固定目录和 `code .` | 在任务卡标记当前步骤，不追问路径理论 |
| 18～30 分 | 沿阶梯推进 | 核查学生是否混淆 PowerShell 与 WSL Bash | 完成 VS Code 接入、课程目录和标记文件 |
| 30～40 分 | 状态检查后继续 | 集中回应共同问题；个别 VS Code Server/网络问题准备转状态记录 | 运行证据命令并现场核对预期结果 |
| 40～50 分 | 最终收口 | 停止个别排错，核验 `READY-CODE` 或 `BLOCKED-*` 是否可接续 | 提交证据，记录课外继续位置 |

**弹性块**：让快组从另一个目录重新打开并比较；首轮不讲路径概念。

**超时删减顺序**：先删快组变体；再删路径术语；再把个别 VS Code 故障转课后。`code .` 演示和最终状态提交不可删除。

## 无助教时的处理顺序

1. 立即处理密码、未知管理员脚本、删除数据等安全问题；
2. 同一问题阻塞 5 人以上时暂停全班并统一说明；
3. 其余个人问题先提交结构化状态，不按举手顺序逐台接管；
4. 已完成者核对自己的证据或做弹性块，不充当系统管理员。

课外补做累计 1 小时仍未完成时，停止随机尝试并更新 `BLOCKED-*`。W2 会正式教授路径含义；W1 复制固定命令成功不等于已经理解路径。

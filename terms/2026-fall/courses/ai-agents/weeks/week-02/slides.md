# 一次可信运行，要经过一条完整链

```text
远端仓库 → 本地项目 → 当前目录 → 项目环境 → 运行 / 测试结果
```

# 90 秒说明只回答五件事

1. 项目从哪里来；
2. 本地项目与当前目录在哪里；
3. 使用的是哪个项目环境；
4. 运行和测试留下了什么；
5. 这些证据仍不能证明什么。

# 两人一组，核对而不是代做

## 已运行

<!-- column -->
## 仍受阻
**复述断点**

确认最后成功处、完整错误和下一步。

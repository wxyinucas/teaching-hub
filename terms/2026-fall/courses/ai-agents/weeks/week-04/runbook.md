# W4｜把 Agent 接入现实系统

> AI Agents · W4 · 3 × 50 min · 约 25 名零编程基础学生 · 无助教

## 本次课

- 根问题：当 Agent 要使用真实的外部服务时，人怎样只交出完成任务所需的权限，并证明调用确实成功？
- 最低出口：学生本人在 SG 路线看到 `Demo A/C`，只授权 `Basic data access`，并从本机成功执行固定的 AAPL 历史日 K 调用；能够指出返回的 6 个交易日，并如实说明是否由本人完成。
- 硬收口：第一课时第 42 分钟停止新开注册支线；第二课时第 45 分钟停止生成新授权码；第三课时第 38 分钟停止新调用与排障，只保留 Revoke 与 logout。受阻者转用教师脱敏记录，但不得写成本人完成。

## 第一课时 · 讲与进入：取得可用的模拟环境

### 0-10 | 先看完整责任链

> 收口：“接入成功”必须回答三件事：以谁的身份、拿到什么权限、哪次响应证明可用。

- 课前：打开 Slides“第一次外部调用，也是一条责任链”；准备不含账号信息的最终状态页面。
- 展示：`注册 → 身份认证 → 权限授权 → 工具调用 → 检查成功与拒绝 → 撤销并退出`。
- 问：Agent 说“已经接上平台”，我们至少还要知道什么？
- 说：身份、权限、真实响应，三项都需要证据。
- 限定：本周只读历史行情；不申请真实证券账户、不入金、不读账户、不查订单、不交易。

### 10-20 | 分清注册、认证与授权

> 收口：“账号存在、平台认出我、工具被允许做什么”，分别是注册、认证和授权。

- 课前：打开 Slides“三道门，回答三个问题”和“本周只保留一条入口”。
- 展示：注册、身份认证、权限授权三栏。
- 说：注册解决“有没有账号”；认证解决“是不是本人”；授权解决“工具能做什么”。
- 问后自答：登录成功等于 Agent 可以交易吗？不等于。
- 固定路线：`SG 账号 → open.longbridge.com → Demo A/C`；只有教师判断 `.com` 不可用时才切换入口。

### 20-42 | 注册或登录，看到 `Demo A/C`

> 收口：“亲眼看到 `Demo A/C`”才算进入；否则只记录卡在哪一步。

- 课前：确认 `https://open.longbridge.com/connect` 可访问；准备一张教师脱敏证据卡作为 Plan B。
- 展示：SG 地区、邮箱登录、`Open Mock Account` 与 `Demo A/C` 的位置，不展示个人信息。
- 让学生做：按 Guide 使用本人邮箱进入 SG 路线，并打开模拟账户。
- 巡视只查：域名正确、地区为 SG、邮箱认证完成、页面出现 `Demo A/C`。
- 停止：同一失败只有出现新信息时再试一次；不换地区、不建重复账号、不申请真实账户。
- 提醒：验证码、邮箱、手机号、姓名和账号编号不投影、不截图、不交给 Agent。
- 到点：第 42 分钟停止新开注册支线。

### 42-50 | 用两个状态结束第一课时

> 收口：本节只留下“能进入”或“不能进入”，不接受“应该可以”。

- 展示：Slides“第一课时只留下两个状态”。
- 让学生写：`能进入：本人已看到 Demo A/C`；或 `不能进入：当前页面／动作 + 可公开的错误类别`。
- 统计：记录两类人数，只用于后续备课，不做课堂排名。
- 分流：能进入者按 Guide 安装 CLI，只做到 `longbridge --version`；不能进入者解释教师脱敏证据卡。
- 预告：下一课时从 CLI 与最小权限开始，不继续占用主线做注册排障。

## 第二课时 · 做：用最小权限完成真实调用

### 0-12 | 安装并确认 Longbridge CLI

> 收口：终端能显示 Longbridge 版本，才进入授权；不能显示就留下真实错误并切换 Plan B。

- 课前：在教师 WSL 中重新跑通 Guide 的安装步骤、`uname -s`、`longbridge --version` 和 `longbridge auth login --help`。
- 说：CLI 是本机向平台发请求的工具，不是 Agent，也不是模型。
- 让学生做：按 Guide 在 WSL 中安装，并依次运行上述三个检查。
- 检查：`uname -s` 显示 `Linux`；版本命令有输出；帮助中出现 `--auth-code`。
- 排障只查：是否误用 PowerShell、安装是否成功、`/usr/local/bin/longbridge` 是否存在。
- 到点：第 12 分钟仍无版本输出者保存错误，改用教师脱敏记录跟随。

### 12-23 | 只选择 `Basic data access`

> 收口：本次授权只能读基础行情；账户、订单和交易能力全部关闭。

- 课前：确认授权页可打开；准备 Slides“本周只开一扇门”。
- 让学生做：创建易识别的授权名称，例如 `W4 Basic Data s07`。
- 保留：`Basic data access`。
- 关闭：`Watchlist`、`Account & Positions`、`Trade Order Lookup`、`Trade Execution`。
- 检查：生成授权码前，让学生逐项对照投影；无法确认就不生成。
- 说：安全边界来自平台拒绝越权请求，不来自“相信 Agent 不会乱做”。

### 23-35 | 由本人安全兑换授权码

> 收口：只认 CLI 明确报告授权成功；授权码本身不留下任何课堂记录。

- 课前：准备一段无真实授权码的终端演示；确认教师账号可在 Authorized Apps 中找到本次授权。
- 先做：停止 Agent 当前动作，在 WSL 中准备好以下命令，再回网页生成一次性代码。

```bash
read -r -s -p "Paste W4 auth code: " W4_AUTH_CODE
echo
LONGBRIDGE_REGION=global longbridge auth login --auth-code "$W4_AUTH_CODE"
unset W4_AUTH_CODE
```

- 提醒：授权码不截图、不投屏、不进对话、不进文件、不进 Git、不直接写进命令历史。
- 检查：只接受 CLI 明确的成功结果。
- 失败：先核对 `.com`、SG 与 `LONGBRIDGE_REGION=global`；只有信息发生变化才生成新代码。
- 到点：第 35 分钟仍未成功者留下错误类别，不继续猜测授权状态。

### 35-50 | 让 Agent 只执行固定请求

> 收口：本人看到固定请求返回 6 个交易日，才算完成本周核心调用。

- 课前：打开 Slides“让 Agent 只完成一次明确调用”；备好 6 个日期的教师脱敏记录。
- 让学生做：复制整段 Prompt；Agent 先解释命令，学生确认后才允许执行。
- 执行：只运行以下请求，不运行其他 Longbridge 命令。

```bash
LONGBRIDGE_REGION=global longbridge kline history AAPL.US \
  --period day --start 2025-01-02 --end 2025-01-10 \
  --adjust none --format json
```

- 检查请求：`AAPL.US`、日线、`2025-01-02..2025-01-10`、不复权、JSON。
- 检查响应：共 6 条，日期为 1 月 2、3、6、7、8、10 日；不记录价格或完整 JSON。
- 记录：只写“本人调用成功／尚未成功”、行数和日期；教师示例必须标成“教师示例”。
- 到点：第 45 分钟停止生成新授权码；最后 5 分钟只记录当前节点。

## 第三课时 · 验证与收口：检查拒绝并撤销授权

### 0-12 | 给未完成者最后一次恢复窗口

> 收口：第 12 分钟后不再做个人平台排障；每个人都带着真实证据进入边界判断。

- 课前：准备六行脱敏证据和缩短日期区间的安全变体。
- 让未完成者做：只从上次记录的节点继续，不从头重来。
- 教师只处理：能帮助多人、且能产生新信息的共同问题。
- 让完成者做：解释六行脱敏证据；再预测把结束日期改成 `2025-01-03` 会返回几条。
- 到点：第 12 分钟停止平台排障，未完成者转用教师示例且个人状态保持“尚未完成”。
- 统计：记录此时真正完成个人固定调用的人数。

### 12-25 | 用拒绝检查账户权限

> 收口：行情成功证明“允许的能力可用”；账户读取被拒绝只证明“账户读取没有授权”。

- 课前：确认教师授权仍有效，并备好以下只读检查。

```bash
LONGBRIDGE_REGION=global longbridge assets --format json >/dev/null
echo "ASSET_EXIT=$?"
```

- 让学生做：运行一次；只看是否被拒绝，不收集错误全文。
- 预期：`ASSET_EXIT` 非 0。
- 异常：若 `ASSET_EXIT=0`，不再运行、不查看或展示资产内容，立即进入 Revoke，并记录“权限范围错误”。
- 说：授权页说明勾选了什么；行情成功说明基础行情可用；资产失败只说明没有账户读取能力。
- 限定：不新增 Watchlist、订单或交易接口测试；教师示例不得写成个人验证。

### 25-38 | 先远程 Revoke，再本地 logout

> 收口：服务器拒绝旧授权，而且本机 token 已清除，本次授权才真正结束。

- 课前：打开 Authorized Apps；备好固定 K 线命令和 logout 命令。
- 让学生做：在网页找到 `W4 Basic Data sXX`，执行 Revoke。
- 验证远程：再次运行固定 K 线命令，确认服务器拒绝。
- 清理本地：运行以下命令。

```bash
longbridge auth logout
longbridge auth status
```

- 说：Revoke 终止服务器授权；logout 清除本机 token；二者不能互相替代。
- 到点：第 38 分钟停止新调用、功能探索与排障，只保留必要的 Revoke 与 logout。
- 检查：只要 `auth login` 成功或 Authorized Apps 中仍有本次授权，就必须完成清理后再离场。

### 38-50 | 留下一张脱敏记录

> 收口：只留下可公开核验的事实、证据边界和个人完成状态，不留下秘密或完整行情。

- 课前：确认 Guide 中的报告模板可用；准备打开 `students/s07/weeks/week-04/report.md`。
- 让学生写：是否看到 `Demo A/C`、实际权限、固定请求、行数与日期、资产请求结果、Revoke 与 logout 状态。
- 禁止写入：授权码、token、账户编号、完整响应和价格。
- 判定核心完成：本人看到 `Demo A/C`，且本人固定调用成功；两项缺一即为“否”。
- 判定安全离场：建立过授权者已完成网页 Revoke 与本地 logout；这与核心完成分别判断。
- 补一句：`我检查了______，因此目前只能支持______，仍不能支持______。`
- 结束：记录最终个人完成人数；展示 W5 预告，不提前开发策略或订单。

## 临场取舍

- 慢了：保留注册／认证／授权三分法、最小权限、固定调用与 Revoke + logout；第三课时第 12 分钟后统一切到教师脱敏记录。
- 快了：依次做“解释六行证据 → 预测并缩短一次日期区间 → 让 Agent 解释整条链”；教师随时喊停，不探索新接口。
- 坏了：暂停真实平台路线，关闭 Agent，使用教师脱敏记录完成证据判断；个人状态仍写“尚未完成”，只从真实阻塞点续做。

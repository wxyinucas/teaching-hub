# 让 Agent 只完成一次明确调用

我们现在只验证一次 Longbridge 基础行情调用。不要枚举或读取已有环境变量，不要读取、显示或寻找授权码、token、账户信息和本地凭据文件；允许按给定命令为当前进程设置公开且非敏感的 `LONGBRIDGE_REGION=global`。不要修改授权，不要查询资产、订单或交易，也不要创建或修改项目文件。

请先解释下面命令中的标的、周期、起止日期、复权方式和输出格式；等我确认后，只运行这一条命令：

`LONGBRIDGE_REGION=global longbridge kline history AAPL.US --period day --start 2025-01-02 --end 2025-01-10 --adjust none --format json`

执行后只报告是否成功、记录数、每条记录的 `time` 和字段名称；不要复述价格或完整 JSON，不要运行其他 Longbridge 命令，也不要提交文件。完成后停下来，等我核对。

# 撤销与退出发生在两个位置

```text
网页 Revoke
→ 服务器不再接受授权
→ 再次调用被拒绝

longbridge auth logout
→ 清除本机保存的 token
```

本地显示“有 token”，不等于服务器仍然接受它。

# 这些证据把我们带到哪里？

<!-- column -->
## 可以支持
**本次边界按预期工作**

- 本人进入模拟环境

**现实仍然存在不确定性**

- 平台永远可用
- 数据绝对正确
- Agent 永远不会出错
- 策略将来能够盈利

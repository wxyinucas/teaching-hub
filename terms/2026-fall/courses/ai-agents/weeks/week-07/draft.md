# W7 备课草稿

## 主线

**Debug｜结果不对，偏差最早发生在哪一步？**

固定输入复现 → 提出两个可能的原因 → 在能区分它们的位置观察 → 修复 → 重跑原用例和一个变式。学生用 VS Code 的 Python 调试器，练习继续放在 Notebook。GDB／LLDB 留作可省略的教师对照。

## 课前双机演练

- [ ] 两台电脑在 VS Code 装好 Live Share，一台当学生机，一台当授课机。学生机打开 W6 练习目录和 Notebook 副本，启动共享。授课机用邀请链接加入，打开同一个 cell。
- [ ] 在授课机加入之后，回学生机运行一次错误版本，再修改并重跑。只在授课机上观察，确认代码和两次运行的输出或报错都看得到。
- [ ] 在实际上投影的设备上确认能放大到看清代码和输出。课堂若连不上或输出不更新，切回教师预备的两份输出，继续对照。

## 课堂检查点：每人展示一次修改过程

每课时先选一道检查题。发题时说明：「先在自己的 Notebook 里做。到时间和旁边同学交换展示，每个人都要用自己的代码跑一遍。」

1. **同桌轮换，约 5 分钟**。每人打开自己的 Notebook，展示用哪组输入复现、在哪里停住、当时看到了什么值，再指给对方看改动并重跑。另一人负责对照预期结果，可以追问「这个值怎么帮你确定该改这里？」
2. **中途也能展示**。还没修好就重跑故障，给同桌看已经查过的一个停点，并说下一步要检查哪个值。教师巡视时抽看几组的实际操作。
3. **全班只看一次 Live Share，约 5 分钟**。从已看过的过程里挑一份有代表性的，请该同学共享并重跑。若共享只同步 Notebook 输出，就把关键变量用 `print` 留在 cell 输出里。教师接过解释，全班回到本机核对同一个现象。

## 开场约 30 分钟

演示只用一个例子。均值函数直接调用结果正确，报告却把两组数据的均值都算成 `6`，预期是 `6` 和 `3`。

- **0–5 分钟**。Slides 放两组输入和预期结果。先看失败输出，猜是函数算错了，还是第二次传错了数据。
- **5–15 分钟**。切到 Notebook，在均值函数入口下断点，用 **Debug Cell** 运行报告。看第二次收到的 `values`，切到调用栈上一层找实参，改一处并重跑检查。
- **15–30 分钟**。学生打开 Notebook，在题一自己停一次、看一个值、重跑检查。后续进入同桌轮换展示，再从实际结果里选一份给全班看。

## 六道练习题案

每题给可直接运行的错误版本和固定输入。公开检查至少有一例能拒绝错误版本，以及一例能检验修复是否只对给定输入有效。题一至四练不同的定位方法，题五和六可随进度展开。表内观察点供教师备课，学生先读场景和规格，再自己选断点。

| 题目 | 复现与验收 | 调试时要区分什么 |
| --- | --- | --- |
| 1. 有效的 `0` 消失了 | `[0, None, 6]` 只剔除缺失值，保留 `[0, 6]`，均值应为 `3`。错误版得到 `6`。再检查 `[0, 0]` 的均值仍为 `0`，全缺失时返回 `None`。 | 是筛选把 `0` 丢了，还是均值算错了？在筛选分支停一次，观察 `value` 和保留下来的数据。 |
| 2. 校正函数单测通过，报告却算反了 | 测量原值 `12`、仪器偏移 `3`，校正值应为 `9`。直接调用通过，报告却输出 `-9`。换成原值 `4`、偏移 `7` 时应为 `-3`。 | 是校正公式出错，还是报告的参数传反？在函数入口看两个参数，沿调用栈回到出错的调用位置。 |
| 3. 最后一个窗口去哪了 | `[2, 7, 4, 1]` 按长度 `2` 的滑动窗口求和，应得 `[9, 11, 5]`，错误版少了 `5`。窗口长度等于数据长度时应有一个结果，长度为 `1` 时应原样返回各元素。 | 最后一个窗口算了但没收进结果，还是循环从没走到那个起点？分别观察循环次数和结果列表长度。 |
| 4. 迟到的旧数据覆盖了新数据 | 输入 `(编号, 时间, 值)` 依次为 `A,2,20`、`B,1,7`、`A,1,10`、`B,3,9`，应保留 `A:(2,20)` 和 `B:(3,9)`。交换不同时间的到达顺序，结果应相同。 | 是不同编号串了记录，还是同一编号更新时丢了更新的那条？在处理第三条记录时检查已有状态和更新条件。 |
| 5. 步长在减半，试点却越走越远 | 给定 `f(x) = (x - 3)²` 和起点 `x = 0`。从同一个起点沿给定方向 `+6` 试步，步长从 `2` 开始，每次失败就减半，只接受使 `f` 严格变小的试点。应尝试 `12, 6, 3`，在第三次接受。错误版试到 `12, 18, 21, 22.5` 都失败。换起点 `4` 和方向 `-2`，应试到 `0, 2, 3`，同样第三次接受。 | 步长没减半，还是把上一个被拒绝的试点当成了新起点？观察第二次试步时的步长、起点和试点。公式及更新规则由题面给出。 |
| 6. 修好组内结果，整体均值还是错的 | A 组 `[0, None, 6]`、B 组 `[12]`，A 均值应为 `3`、B 为 `12`、整体为 `6`。单修筛选后组内值正确，整体仍为 `7.5`。再用没有 `0`、但组大小不同的输入检验整体均值。 | 两处错误要用不同用例拆开。一个用例抓有效值被删，另一个抓错误地对组均值再求均值。先确认第一个修复有效，再沿汇总过程定位第二个错误。 |

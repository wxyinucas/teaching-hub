# W7 备课草稿

## 已进入材料的设计

主线与课堂步骤见 `runbook.md`，六题的规格、错误代码和检查见学生仓库 `week-07/exercises.ipynb`。本轮改用 NumPy 数值计算，依次观察掩码、广播、窗口聚合、排序索引、向量试步、分组与总体均值。

教师在浏览器 Jupyter 演示，Notebook 保留折叠的 VS Code 步骤。每课时选一道检查题，两人轮流展示输入、停点与实际值、改动和重跑结果。全班选一份过程通过 Live Share 对照。

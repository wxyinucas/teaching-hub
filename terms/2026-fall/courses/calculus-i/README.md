# 高等数学（上）

本课程按 96 课时设计：共 48 次课，每次 2 课时、每节 50 分钟，约 100 名学生。**小专题是内容组织、备课放行与网站导航的基本单位**；自然周不进入文件层级，每次课在标题附近标注实际日期。

课程地图已依据 2026 秋季教学日历与课程执行大纲完成校订，不继承其中的具体日期。两份校方文件对分项课时的归属与合计仍有待课程组确认之处；本课程暂以两份文件共同声明的 96 课时和完整内容范围为硬约束。全课程划分为 17 个小专题，合计预估 48 次课；最后 4 次课中，首次作为硬机动，其后至少 3 次用于总复习。

专题台本按“专题 → 若干次 100 分钟课 → 每次课两张 50 分钟卡片”组织。每次课只使用 `0-50` 与 `50-100` 两个三级标题；卡片内部使用具有实际含义的四级标题形成视觉分段，不再用分钟数切碎内容，也不显示“推进”“阶段”等空标签。

- `course.json`：登记完整专题地图；地图条目不表示对应专题已经备好。
- `course-design/topic-map.md`：保存 2026 校订依据、17 个专题的容量、边界与先后关系。
- `course-design/topic-runbook-contract.md`：定义专题台本、脚手架与共享材料的边界。
- `course-design/topic-runbook-template.md`：可解析的课程专用模板；只提供结构，不是正式专题。
- `topics/`：只在专题真正进入制作时建立对应目录，不预先生成空目录和占位材料。

## 材料原则

- 台本是每个专题唯一必需的核心材料，先冻结相关内容，再决定是否派生其他材料。
- 台本正文只保留明确结论和台上可直接使用的提示，不承担教师与协作者之间的沟通。阶段性准备事项只放在相关内容段最前的“课前检查”，解决后删除或转化为正文结论；最终验收前统一清理。
- 每次课先排出完整的 0–100 分钟主线，另备约 20 分钟可选补充；补充就近附在相关知识点后，默认跳过，不计入时间轴，也不推迟后续节点。
- 每轮备课覆盖大约 3 次课的工作量。已经讨论清楚的部分写成详细台本；尚未细化的部分保留结论、承接、板书或例题位置和可选方向，随后在原处替换为正式内容。
- 板书是默认课堂载体。Slides 主要用于教师课前演练板书结构；只有必须共同观看的直观内容才登记为课堂资源。
- Guide 不默认生成；只有学生确实需要独立执行、核验或课后接续时才建立。
- Runbook、Slides、Guide 与 Demo 都归整个专题共享；暂不为单次课拆分资源，也暂不增加专题资源目录。
- 鼓励按实际需要高频制作辅助学习资料，但不预设固定格式或固定材料包。
- 教材只提供知识范围和顺序，不直接提供根问题、教学路径、代表题或学习证据。
- 目录中带 `*` 的内容不进入课程结构；教师可在教学过程中自行选择加入。工程应用与数学发现／数学思维只作为章末或专题末的可选收束素材。
- 正式专题台本完成后登记为网站公开资源；课堂例题只在台本中记录教材、题库或纸质教案的定位编号与用途，不抄录完整题目。

# 高等数学（上）

本课程按 96 课时设计：16 周，每周 3 次课、每次 2 课时，每节 50 分钟，约 100 名学生。**一周是备课与放行单位**；三次课是周台本内部的推进节点，不各自建立一套材料。

周台本按“整周 → 三次 100 分钟课 → 每次课 6–10 个微段”组织。每次课的微段时间从 0 连续写到 100；第 50 分钟只标记两节课之间的视觉边界，不单独成为内容卡片。三级标题建立微段，正文优先用简短 bullet 整理讲解、重点、例题占位和必要收束；四级标题只在卡片内部确有需要时使用。

- `course.json`：登记完整 16 周课程地图，不表示对应周已经备好。
- `course-design/16-week-blueprint.md`：保存章节周数、每周主题与维护边界。
- `course-design/weekly-runbook-contract.md`：定义周台本需要回答的问题、滚动冻结方式与材料边界。
- `course-design/weekly-runbook-template.md`：可解析的课程专用模板；只提供结构，不是正式教学周。
- `weeks/`：只在某周真正进入制作时建立 `week-XX/`，不预先生成空目录和占位材料。

## 材料原则

- 台本是每周唯一必需的核心材料，先冻结台本，再决定是否派生其他材料。
- 每次课先排出完整的 0–100 分钟主线，另备约 20 分钟可选补充；补充就近附在相关知识点后，默认跳过，不计入时间轴，也不推迟后续节点。
- 板书是默认课堂载体。Slides 主要用于教师课前演练板书结构；只有必须共同观看的直观内容才登记为课堂资源。
- Guide 不按周默认生成；只有学生确实需要独立执行、核验或课后接续时才建立。
- 鼓励按实际需要高频制作辅助学习资料，但不预设固定格式或每周材料包。
- 教材只提供知识范围和顺序，不直接提供根问题、教学路径、代表题或学习证据。
- 目录中带 `*` 的内容不进入课程结构；教师可在教学过程中自行选择加入。工程应用与数学发现／数学思维只作为章末周的可选收束素材。
- 正式周台本完成后登记为网站公开资源；课堂例题只在台本中记录教材、题库或纸质教案的定位编号与用途，不抄录完整题目。

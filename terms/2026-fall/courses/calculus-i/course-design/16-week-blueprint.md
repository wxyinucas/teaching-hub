# 高等数学（上）：16 周课程蓝图

> 状态：首版结构基线。只依据教材目录划分知识范围，不继承教材正文、例题、讲解或评价方式。

## 课程现实条件

- 总量：96 课时。
- 周期：16 周；每周 3 次课，每次 2 课时。
- 规模：约 100 名学生。
- 默认课堂载体：板书。
- 备课与放行单位：一周；每次课只是周内推进节点。

| 周次 | 内聚主题 | 教材目录范围 |
| --- | --- | --- |

| W6 | 从局部导数推断整体行为 | 微分中值定理、洛必达法则 |
| W7 | 近似与函数形态判断 | 泰勒公式、函数单调性、曲线凹凸性 |

| W9 | 把求导反过来 | 原函数与不定积分；换元积分法 |

| W11 | 从无限累加到基本公式 | 定积分的概念与性质、微积分基本公式 |
| W12 | 用定积分计算几何量 | 定积分的换元与分部积分；面积、体积、弧长 |
| W13 | 用积分建模并突破有限边界 | 定积分的物理与工程应用、广义积分 |
| W14 | 从变化规律建立一阶微分方程 | 基本概念、可分离变量方程、齐次方程 |
| W15 | 用变换处理一阶与可降阶方程 | 一阶线性方程、变量替换、可降阶高阶方程 |
| W16 | 高阶线性方程及全课程收束 | 高阶线性方程、二阶常系数方程、工程应用 |

## 周与课次的关系

- 每周只设一个根问题、一个最低出口和一个硬收口。
- 三次课分别承担同一主线的阶段任务，只设置阶段落点和停止线。
- 周内可以重新分配进度；跨周结转必须回写课程地图或下一周台本，不以临场拖延代替计划变更。
- 主线按全周可用容量的约 80% 安排；每次课仍需保留安全收口，不用全周余量掩盖单次失控。

## 内容层级

- **主线层**：支撑本周根问题和最低出口的内容。
- **扩展层**：目录中带 `*` 的内容，以及只有容量允许时才进入的补充内容。
- **章末收束层**：工程应用举例与数学发现／数学思维，用于连接、概括或检验本章主线，不单独占用零散周次。

本蓝图只确定容量与边界。具体定义怎样引入、哪些推导进入板书、采用什么代表题以及如何取得学习证据，均在对应周开始备课时决定。

# 扩散模型自学课

用费曼学习法组织扩散模型的学习：通过自己讲解、绘图、关键推导和小规模代码，发现并补足理解缺口。T00 保留为课程导论，后续以 Simon J. D. Prince 的《Understanding Deep Learning》为教材主线；[教材与专题地图](course-design/topic-map.md)统一记录章节映射、选读范围与学习顺序。

当前为课程设计工作版。第一轮参考体量为暑期课程的 4 周、每周一次、每次两节左右；这只是容量参照，专题数量、课次和时长随实际理解程度调整。

## 三种学习身份

| 学习身份 | 学习目的 |
| --- | --- |
| 初学者，尚不知道自己不知道什么 | 快速找到问题、对象和关系的锚点，建立能讲清扩散模型的完整图景 |
| 已有初步理解，但还不稳定 | 比较同类生成模型与扩散内部不同范式，解释设计差异、特点和适用条件，把理解落实 |
| 尝试深入科研探索 | 面对新课题，能独立判断是否适用、怎样融合、哪些假设需要改变，以及判断的依据与边界 |

三种身份描述理解状态。Topics 按完整的问题链组织，大小可以不同，同一个关键问题可以在后续阶段重新深入。T00–T03 对应第一轮主线，T04 为比较阶段占位，T05 为科研迁移占位；后两阶段的具体内容随第一轮学习结果逐步确定。学习中发现新问题时，再决定增加哪些章节、材料或专题。研究方向保持开放，生存分析是可能的背景与备选方向。

## 当前学习起点

- 有统计建模背景，已能用模式、变化、特征之间的依赖、条件分布和采样来理解生成任务；也能根据任务条件判断生成结果是否遗漏了目标分布的一部分。这些是可调用的直觉，后续需与数学表达和模型计算对应。
- 已有诊断中，能正确判断独立高斯噪声不会把非高斯变量严格变成高斯变量；不把这一点列为概率基础缺口。
- 长期使用 Python，有 NumPy 经验，近五年主要使用 Rust。约十二年前接触过深度学习，尚未使用 PyTorch，也没有亲自训练神经网络的经验。
- 保留了神经网络是参数化函数族的印象；需要重新建立层、参数、激活函数与前向计算的直观，并分清表达能力、训练与泛化。
- 重点补足损失、梯度、计算图、反向传播、参数更新、学习率与小批量训练；明确参数梯度与输入梯度，以及求梯度与更新参数的区别。
- 平方损失与条件期望需要简短复习，并连接到去噪。点预测、分布建模和采样之间的区别继续通过具体例子落实。

## 第一轮学习出口

- 能用自己的话讲清扩散模型解决的问题、基本数学直观、结构动机，以及训练与生成各自的作用。
- 能把应用、简单数据、公式、结构图和代码对应起来。入口顺序采用“问题与用途 → 整体地图 → 核心直观”；用应用提出问题，用一维或二维数据解释关系，再回到应用。
- 能用少量关键推导支撑直观，说明关键步骤的依据与结论的适用条件。AI 可以协助展开推导。
- 能读懂、改动并解释一个完整的小规模 CPU 例子，核对 agent 写出的代码是否对应预期的数学过程。独立手写训练循环以后可另设专题。

网络表示与参数学习合并为 T01，共用一个小例子，并保留两个理解环节。参数学习保留一次有完整上下文的手算：从数据、预测任务、固定量和待学参数出发，计算预测、损失、梯度与参数更新，观察更新后的变化，再与代码中的同一次计算对应。

T02 把为什么去噪、怎样学习去噪以及怎样生成样本连成一个专题，训练与生成仍分别检查理解；T04 合并模型间比较与扩散内部比较。合并调整组织边界，不减少既定的关键知识，也不要求一个专题在一次课内完成。

## 组织与材料约定

通用备课方法以 [docs/prep-system.md](../../../../docs/prep-system.md) 为准。主要参考高数课程按问题组织专题、逐步细化近期内容的方式。

本课程的讲解方式见[学习与讲解方法：直观、数学与程序的对应](course-design/learning-method.md)，记录三种表达的映射、section 与 topic 中的安排，以及主教材和对照材料的分工。

- Topic 是内容组织与备课放行的基本单位。备课时在设计稿中明确问题、学习目标与范围；这些判断不再以“根问题、最低出口、硬收口”等顶部卡片展示。课次与时间只作可调整的检查点。
- 先在问答中形成共识，再写台本工作版；内容变化先回写台本。Slides、Guide、Demo 依实际用途派生，完成后清理制作提示并冻结相应台本。
- 只有专题真正进入制作时才建立专题目录；资源完成后再登记。课程设计层保存阶段目标、专题边界与学习起点，具体教学内容归专题台本。
- 先给知识清单和选项，按需展开；近期内容详细准备，远期内容保留开放空间。
- T01 起，一个 section 对应一次课，是连续讲解与课末复习的完整单元。专题开头只保留简洁路线：每个 section 一行概括，不嵌套项目符号和数字条目。section 内用小标题组织讲解，末尾集中列出复习问题、核对要点、记录与接续。一次课包含多少课时、持续多久，按内容与实际学习情况安排，具体见 [T01 Section 组织稿](course-design/t01-section-plan.md)。
- 新内容用 `T01 S1` 定位：`T` 表示专题，`S` 表示 section，个位编号不补零；内部 `1、2…` 表示讲解环节，不代表课时。自学需要中途暂停时记录 section 与具体标题，授课日期与时长另行安排。
- T00 已有的两课时编排与 `T00 L1 P1` 定位保留；`L` 表示课次，`P` 表示课时，不将这一时间结构强加给新专题。
- Runbook 保存能用于自讲的解释、关键推导、典型疑问回应与操作讲评；读到一个导问时，也能找到相应的回答依据。先按完整讲解与操作试讲，再核定课时容量。
- Slides 承担课程 PPT 的职责，用于课堂呈现问题、图示、公式与必要对照。Guide 收录需要实际完成的操作、输入材料、记录方式与参考核对，支持先做再看答案。

当前暂缓 SDE、Itô 微积分、完整变分下界推导和复杂 CNN／Transformer 架构。常见网络组件的作用、图示和设计动机属于第一轮的理解范围。实验规范、消融与投稿政策留到研究问题形成后讨论；环境安装和训练工程按后续实际学习任务决定。

## 主教材与补充材料

主教材采用 Simon J. D. Prince 的 [Understanding Deep Learning](https://udlbook.github.io/udlbook/)（《理解深度学习》）。第一轮以第 2–7 章的必要基础和第 18 章的机制为主干，其余章节按问题选读；第 15–17 章进入比较阶段。具体范围与顺序以[教材与专题地图](course-design/topic-map.md)为准，不要求从第 1 章顺读到第 21 章。

第 18 章分两次读：第一轮先理解去噪训练与采样，后续补第 17 章后回读完整 ELBO 推导。教材阅读是自己的学习与备课范围，不等于对外科普课必须逐项覆盖的授课量。私人译稿用于辅助阅读，关键推导与存疑处回查英文原书。

以下材料按需补充：

- 《动手学深度学习》中文版 PyTorch 版本：§3.1 线性回归、§4.1 多层感知机、§4.7 前向传播、反向传播和计算图。
- PyTorch 官方 Learn the Basics：Tensors、Build Model、Automatic Differentiation、Optimization Loop。
- Bishop《Pattern Recognition and Machine Learning》§1.5.5 Loss functions for regression。

这些补充材料用于定点补足，不另设并行主线，也不视为已经学完。

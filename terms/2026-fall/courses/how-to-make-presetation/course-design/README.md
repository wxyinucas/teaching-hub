# 课堂表达自学课：材料契约

这门课供教师自学与试讲，关注组织、衔接和宏观节奏。一个完整学习单位是一份原材料及一次小迁移；不按固定教学周排列，也不规定每份材料必须占满一节课的分钟数。

## 组织与材料职责

- 同一作者的材料放在 `authors/<author>/materials/`；每份材料有自己的目录与来源登记。目录次序用于查找，不表示必修学习顺序。
- **材料笔记**复用 Guide：用自己的话整理原作的论证顺序、关键观点和案例，保留来源。作者主张、我们的解释和课堂迁移分别标明。
- **方法演示**复用 Slides：用作者介绍的方法组织这份材料的讲解。允许重排原作，不把新示例写成作者的原话或原例。
- **我的提示**复用自由卡片：留下自己准备与试讲时可调用的问题、动作和收口。无需分钟标题或固定课时边界。
- 一种职责可以有多份文档，多种职责也可以复用同一阅读器；由每份材料的清单登记。录音复盘需要时另挂，暂不作为每份材料的必备入口。

## 制作与放行

先写学习台本工作版，确定根问题、最低出口与硬收口，再从台本和原材料生成笔记与方法演示。工作版可以保留待讨论问题；派生材料完成后清除已消费的制作提示。

第一份 Duarte 材料暂以“理解方法并完成一次课堂小迁移”为工作目标。完成一份 60—90 秒片段的前后稿即可收住；不扩写整节实际课堂。原作面向推动改变的演讲，课堂应用由本课另外说明。

通用备课方法以 [prep-system.md](../../../../../docs/prep-system.md) 为准。页面选择以 [网站展示能力的查看入口](../../../templates/README.md#网站展示能力的查看入口) 所列实现为准；复用公共样式，适配 Mac／PC 与 iPad。

# 2026 秋季模板

这个目录保存同一学期两门课程共用的内容契约。模板只约束内容结构；颜色、字体、导航和交互统一由网站源码维护。

- `runbook-template.md`：一次完整课堂的一张主台本。
- `slides-template.md`：静态课件页面；`---` 分页，显式布局只有 `cover`、`question`、`columns`、`prompt`。

`columns` 布局采用统一的动态排版规则：

- 纵向保持标题区位置不变，按页面实际存在的 `lead`、分栏主体和 `footer` 内容组高度，自动把相邻区域之间的剩余距离均分；只有一个主体内容组时，将它放在标题以下的剩余区域中央。
- 横向使用等宽的两栏或三栏网格、平衡的左右留白和固定在列边界上的分隔线；实例页不单独调整列宽、坐标或边距。

复制模板到课程的 `weeks/week-XX/` 后填写，不在实例中添加自定义 CSS、HTML 或页面组件。
